# ⚖️ LegalDocAI – Smart Legal Document Assistant  

🚀 **LegalDocAI** is an AI-powered web application that helps analyze and summarize legal documents using **Natural Language Processing (NLP)** and **Machine Learning**.  
This project aims to save time for legal professionals by providing instant, intelligent document insights.

---

## 🧠 Features  

- 📄 Upload or paste legal documents for instant analysis  
- 🧾 Automatic text cleaning and preprocessing  
- 🤖 NLP-based document summarization and keyword extraction  
- ⚡ Real-time backend processing using Flask API  
- 💻 Beautiful and responsive UI built with Tailwind CSS  
- ☁️ Model integration for real-world document use cases  

---

## 🏗️ Tech Stack  

### 🔹 **Frontend**
- HTML  
- Tailwind CSS  
- JavaScript  
- AOS Animation  
- Glassmorphism UI  

### 🔹 **Backend**
- Python  
- Flask  
- NLP (spaCy, NLTK)  
- Transformers (optional for advanced summarization)  
- JSON-based REST API
